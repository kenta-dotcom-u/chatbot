# 🎙️ リアルタイム議事録作成アプリ（Gemini版）

Streamlit と Google Gemini API（`gemini-3.8-flash`）を活用した、会議の音声録音・文字起こし・議事録の自動生成を行うWebアプリケーションです。

会議の区切りごとに音声を録音するだけで、過去の文脈を保持したまま**議題ごとに「議論の要約」「決定事項」「ネクストアクション」をリアルタイムで整理**します。さらに、**ネクストアクションの具体的な進め方（たたき台）や、会議内で出た質問・疑問点への回答案（模範解答）**もAIが同時に提案します。

---

## ✨ 主な機能

- **ブラウザ完結の音声録音:** Streamlit標準の `st.audio_input` を使用し、追加の録音ソフトなしで音声を収録
- **高速なマルチモーダル処理＆自動リトライ:** Gemini 3.8 Flash に音声データを直接渡し、文字起こし・議事録の統合・キーワード抽出を同時実行（サーバー混雑時の自動リトライ・予備モデル切替機能付き）
- **議題別の構造化＆ネクストアクション抽出:** 会話の流れから議題を自動分類し、各議題に紐づく要約・決定事項・ネクストアクション（担当・期限）および全体のTODO一覧をリアルタイム更新
- **模範解答・たたき台の自動提案（NEW）:** 抽出されたネクストアクションの具体的な進め方や、議論の中で出た質問・持ち帰り事項に対する模範解答（解決案）を議題ごとに自動生成
- **ワンクリック用語解説:** 文字起こしから自動抽出されたキーワードボタンをクリック（または任意の単語を入力）すると、会議の文脈を踏まえた意味・解説を即座に表示
- **Markdown出力:** 生成された議事録・模範解答をワンクリックで `.md` ファイルとしてダウンロード可能
