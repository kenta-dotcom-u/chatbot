# 🎙️ リアルタイム議事録作成アプリ（Gemini版）

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://あなたのアプリ名.streamlit.app/)

🔗 **公開アプリURL:** https://あなたのアプリ名.streamlit.app/

Streamlit と Google Gemini API（`gemini-3.8-flash`）を活用した、会議の音声録音・話者識別付き文字起こし・議事録の自動生成を行うWebアプリケーションです。

会議の区切りごとに音声を録音するだけで、過去の文脈と声の違いを保持したまま**議題ごとに「議論の要約（発言者別）」「決定事項」「ネクストアクション」をリアルタイムで整理**します。さらに、**ネクストアクションの進め方（たたき台）や質問への模範解答の自動生成**、**気になるキーワードのワンクリック意味検索**、**過去の会議の保存・途中再開**にも対応しています。

---

## ✨ 主な機能

- **ブラウザ完結の音声録音:** Streamlit標準の `st.audio_input` を使用し、追加の録音ソフトなしで音声を収録
- **声の違いを聞き分ける話者識別:** 声質やトーンの違いから発言者を自動判別（`【発言者A】` や参加者名）し、誰がどの意見やタスクを担当するかを明確化
- **議題別の構造化＆ネクストアクション抽出:** 会話の流れから議題を自動分類し、各議題に紐づく要約・決定事項・ネクストアクション（担当・期限）および全体のTODO一覧をリアルタイム更新
- **模範解答・たたき台の自動提案:** 抽出されたネクストアクションの具体的な進め方や、議論の中で出た質問・持ち帰り事項に対する模範解答（解決案）を議題ごとに自動生成
- **ワンクリック用語解説:** 文字起こしから自動抽出されたキーワードボタンをクリック（または任意の単語を入力）すると、会議の文脈を踏まえた意味・解説を即座に表示
- **会議の保存・途中再開（アーカイブ機能）:** 「新しい会議を始める」を押すと現在の会議を自動保存し、履歴リストからいつでも過去の会議を復元して続きから録音可能
- **Markdown出力＆混雑時自動リトライ:** 生成された議事録・模範解答を `.md` ファイルとしてダウンロード可能。APIサーバー混雑時（503エラー）の自動リトライ・予備モデル切替機能も搭載
