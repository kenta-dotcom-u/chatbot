# 🎙️ リアルタイム議事録作成アプリ（Gemini版）

Streamlit と Google Gemini API（`gemini-2.5-flash`）を活用した、会議の音声録音・文字起こし・議事録の自動生成を行うWebアプリケーションです。

会議の区切りごとに音声を録音するだけで、過去の文脈を保持したまま**議題ごとに「議論の要約」「決定事項」「ネクストアクション（担当者・期限）」をリアルタイムで構造化・更新**します。さらに、会話に出てきた専門用語や気になるキーワードをクリックするだけで、その場で意味を検索・解説する機能を備えています。

---

## ✨ 主な機能

- **ブラウザ完結の音声録音:** Streamlit標準の `st.audio_input` を使用し、追加の録音ソフトなしで音声を収録
- **高速なマルチモーダル処理:** Gemini 2.5 Flash に音声データを直接渡し、文字起こし・議事録の統合・重要キーワードの抽出を1回のAPIリクエストで同時実行
- **議題別の構造化＆ネクストアクション抽出:** 会話の流れから議題を自動分類し、各議題に紐づく要約・決定事項・ネクストアクション（担当・期限）および全体のTODO一覧をリアルタイム更新
- **ワンクリック用語解説:** 文字起こしから自動抽出されたキーワードボタンをクリック（または任意の単語を入力）すると、会議の文脈を踏まえた意味・解説を即座に表示
- **Markdown出力:** 生成された議事録をワンクリックで `.md` ファイルとしてダウンロード可能
